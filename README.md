# RAMSES Matrix Generation Program  
This project implements a RAMSES assembly program capable of generating an **N × N matrix** in memory based on a generator vector **v**, following the specification provided in the course assignment.  

The program must be assembled using **Daedalus** and executed and tested using **Hidra**.

---

## 📌 Problem Description

Given:

- An integer **N** (2 ≤ N ≤ 7) stored at memory address **180**  
- A memory address **MATRIX** stored at address **181**, indicating where the first matrix element must be written  
- A generator vector **v** stored from address **182** to **182 + (N − 1)**  

The program must compute each matrix element according to:

````
aᵢⱼ = 2 * vᵢ if i == j
aᵢⱼ = 2 * vᵢ – vⱼ if i != j
````

## ⚙️ How to Assemble and Run

### **1. Assemble using Daedalus**

Daedalus (online assembler):  
https://www.inf.ufrgs.br/arq/wiki/doku.php?id=daedalus

Steps:
1. Upload your `.rad` source file  
2. Assemble it to generate the `.mem` file  
3. Download the generated memory image

---
### **2. Run and Test using Hidra**

Hidra simulator download:  
https://github.com/petcomputacaoufrgs/hidracpp/releases/tag/v1.2.0

Steps:
1. Open Hidra  
2. Load the `.mem` file generated by Daedalus  
3. Insert test values:
   - Write N at address **180**
   - Write MATRIX at address **181**
   - Write vector v starting at **182**
4. Set program counter to **H00**
5. Execute the program  
6. Inspect memory at the MATRIX location to verify the generated matrix
